# 08: Descobrindo todos os Barbeiros

**What to build:** O Cliente navega por todos os Barbeiros sem busca obrigatória, filtra por nome se quiser e entende quais perfis já podem receber Agendamentos.

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] A página mostra Barbeiros sem exigir um nome de busca.
- [ ] O filtro opcional por nome encontra correspondências parciais sem exigir o nome exato.
- [ ] A lista inclui Barbeiros sem Serviços ou sem horários disponíveis.
- [ ] Os resultados indicam quando o Barbeiro ainda não tem Serviço ou horário para receber Agendamentos.
- [ ] Cada resultado permite abrir o perfil do Barbeiro existente.
- [ ] Donos e Clientes não aparecem como Barbeiros.
- [ ] A listagem, filtro e estados vazios são cobertos por testes de caso de uso e smoke de rota.
